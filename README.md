# Where Did I Put It?

Where Did I Put It? is a simple Android application that helps users keep track of where they stored their personal belongings.

## Features

- Add items and record where they are stored
- Record a specific place or location
- Optionally record a container
- Add notes about an item
- Search saved items
- View recently added items
- View item details

## Technology

- Kotlin
- Jetpack Compose
- Room Database
- Android Studio
- Git & GitHub

## Project Status

🚧 In active development.

## Purpose

This project was created as a practical Android application to solve a common everyday problem while demonstrating modern Android development practices.
